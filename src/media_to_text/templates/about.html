About media / text

A quieter way to
keep the words.

Media to Text is an open-source transcription workspace for recordings that deserve more than a forgotten file name. It turns audio and video into clean text, structured data, and subtitles without sending the media to a hosted transcription API.

01

Local by default

The application runs on the machine or server you choose. Your recordings stay under your control during processing.

02

Practical outputs

Choose plain text for reading, JSON for software, or SRT and WebVTT when the words need to meet a video.

03

Open to improvement

The source code, tests, deployment files, and issue tracker are available in the public GitHub repository.

Built with

A small stack, easy to understand.

FastAPI handles the web layer, HTMX keeps the interface light, Tailwind CSS shapes the pages, and Faster-Whisper performs the transcription.
