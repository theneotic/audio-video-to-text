This page explains what the self-hosted Media to Text application does with files and basic requests. It is general product information, not legal advice. The person or organization operating a deployed copy is responsible for adapting this notice to its actual configuration and legal requirements.

Last updated: August 2026

Recordings and transcripts

When you use a local installation, the media file is processed by that installation. The FastAPI interface writes an uploaded file and its generated outputs under the configured temporary job directory, `.media_to_text_jobs/` by default. The application does not send recordings to a hosted transcription API. Job files remain on the server until the operator removes them or adds an automated cleanup policy.

Private speech downloads

Text submitted to the Private audio form is synthesized by the bundled eSpeak NG engine in the browser on the free Vercel site, so the downloadable WAV text stays on the device. In Docker deployments, the same feature can use the eSpeak NG engine installed on the application server. The text is not sent to a third-party TTS API. The generated WAV or MP3 is held only in temporary browser/server memory and files while the audio is prepared.

Listen preview

The separate Listen preview can use voices exposed by the browser or operating system. Voice availability and processing behavior depend on that device and platform, so the preview is not guaranteed to use the bundled private engine. Use the generated WAV player and download path when you need the documented private behavior.

What this website collects

The default application does not include an account system, analytics, advertising, newsletter form, or database. The web server and hosting provider may still create ordinary technical logs such as IP address, request time, user agent, and error information. Review the logs and infrastructure of the specific deployment you use.

Third-party browser assets

The default frontend loads Tailwind CSS from cdn.tailwindcss.com, HTMX from unpkg.com, and fonts from Google Fonts. A browser may contact those providers to retrieve the assets. If that is not appropriate for your privacy requirements, vendor the assets locally and update the shared template before deployment.

Your responsibilities

Do not upload material unless you have the right to process it. Before exposing the application to other people, add authentication, HTTPS, access controls, upload quotas, storage cleanup, and a privacy notice that accurately describes your deployment. Avoid placing confidential recordings or personal information in public GitHub issues.
